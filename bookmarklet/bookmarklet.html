🎥 Frontend State Recorder — Bookmarklet

Drag the button below into your bookmarks bar. Click it on any website — no source code access, no build step, nothing committed to that site's repo — to start recording clicks, form input, fetch() calls, and errors, then generate a bug report.

1. Where is recorder-standalone.js hosted?

Defaults to this project's own dev server. Change this if you built and hosted the file somewhere else (e.g. GitHub Pages) so the bookmarklet works on sites you don't control.

2. Drag this to your bookmarks bar:

⏺ Record a Bug

3. Use it:
  1. Open the site you want to test (any site — this one, a staging environment, production, whatever you were about to manually test).
  2. Click the ⏺ Record a Bug bookmark. A floating widget appears, identical to the one built into this project.
  3. Click Start Recording, reproduce the bug, click Stop Recording, then copy or download the generated report.

Note: sites with a strict Content-Security-Policy may block the script injection this bookmarklet relies on. If that happens on a given site, the Chrome-extension approach described in the main README's "Bookmarklet" section is the more robust (but heavier to set up) alternative.
